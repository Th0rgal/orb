Revue de `master` (`4dfb4f26`, 2026-10-26) : backend Rust, desktop `orb/`, iOS,
Android, scripts/infra, noyau Lean. Chaque constat ci-dessous a été vérifié par
`git grep` des appelants ou par lecture du code ; les points marqués *(à

installé : les dépendances Cargo ont été vérifiées par grep (aucune inutilisée).

déduplication, **P3** = découpage structurel, **P4** = renommage.
